Internal decision page for Silpo ready-meals / culinary launch: own couriers, Bolt couriers, marketing package, Bolt Plus, and a blended commission with existing dark kitchen / resto.

## Recommendation

Recalculated on `SILPO business model (5).xlsx`: AOV €13, 40,032 orders and OSPD 0.8 on both courier routes. Own-courier product GMV is €520.4k.

Decision metric is Contribution Profit L2 (after demand incentives). EBITDA is not used on the page.

- Own couriers: **8%**, ask 9–10%. CP L2 €15.9k (3.06%). Demand incentives €0, so L1 = L2.
- Bolt couriers: **13%**. CP L2 €22.3k (3.72%). At 12% L2 is only 2.72% after €14.0k DI.
- Bolt Plus: **14%** (12% + 2 p.p.). CP L2 4.72% / €28.3k; 2 p.p. covers Plus DF.
- One rate for stores + DK/resto: **18%** if Silpo delivers, **19%** if Bolt delivers. Dark kitchen and resto already pay 22.5% of product GMV; CP L2 on that base is 6.02%.
